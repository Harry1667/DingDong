# 叮咚到號 — User Flow

## 主要流程：從查詢到追蹤

```
[開啟 App]
    │
    ├─ 有追蹤中的任務 ──► [首頁] 顯示追蹤卡片
    │                         │
    │                         ├─ 點卡片 ──► [追蹤詳情]
    │                         └─ 點「+ 新增追蹤」
    │
    └─ 無追蹤任務 ──► [首頁] 顯示醫院入口 + 搜尋列
                         │
                         └─ 選醫院 or 搜尋
```

---

## Flow 1：選醫院查看進度

```
[首頁]
  │
  ├─ 點地區分類（台北市 / 新北市 / 桃園 / 台中 / 高雄…）
  │     └─ [醫院列表]
  │
  └─ 搜尋列輸入「台大 / 長庚 / 三總…」
        └─ [搜尋結果] → 點選 → [科別列表]

[科別列表] — 顯示該醫院今日有看診的科別 + 醫師人數
  │
  └─ 點科別 → [醫師列表]

[醫師列表] — 顯示該科別的醫師、診間號、目前叫號
  │
  └─ 點醫師 → [追蹤設定]
```

---

## Flow 2：設定追蹤

```
[追蹤設定]
  顯示：醫師姓名、診間、目前號碼

  ┌──────────────────────────────┐
  │  您的掛號號碼？              │
  │  [數字鍵盤輸入]              │
  │                              │
  │  [略過，僅追蹤進度]          │
  └──────────────────────────────┘
      │
      ├─ 輸入掛號號碼 ──► 設定提醒閾值
      │                    │
      │                    ├─ 「差 5 號提醒」（預設）
      │                    ├─ 「差 3 號提醒」
      │                    └─ 「輪到我才提醒」
      │
      └─ 略過 ──► 直接開始追蹤（不設提醒閾值）

                    │
                    ▼
              [開始追蹤] ──► 回首頁，追蹤卡片出現
```

---

## Flow 3：接收通知

```
[背景執行] ── 每 30 秒輪詢 /api/progress/{code}
  │
  ├─ 號碼有更新 + 快輪到 ──► 發本地通知
  │     「江建勰 04診：還差 3 號輪到您」
  │
  ├─ 輪到了 ──► 發緊急通知（聲音加強）
  │     「叮咚！江建勰 04診：現在叫 55 號，輪到您了！」
  │
  └─ 過號了 ──► 發警示通知
        「⚠️ 您的 55 號已過號（目前 57 號）」

[使用者點通知] ──► 開啟 App ──► [追蹤詳情]
```

---

## Flow 4：追蹤管理

```
[首頁追蹤區]
  │
  ├─ 追蹤卡片（最多 3 張）
  │     每張顯示：醫師 / 診間 / 目前號碼 / 我的號碼 / 剩餘號數
  │
  ├─ 左滑卡片 ──► [停止追蹤]（確認後刪除）
  │
  └─ 點卡片 ──► [追蹤詳情]
                  顯示完整資訊 + 手動刷新按鈕
                  [停止追蹤] 按鈕
```

---

## Flow 5：首次開啟（權限申請）

```
[App 首次啟動]
  │
  └─ 顯示通知權限說明頁
       「開啟通知，輪到您時即時提醒」
           │
           ├─ 允許 ──► 系統通知授權彈窗 ──► 首頁
           └─ 稍後 ──► 首頁（追蹤時再提示）
```

---

## 畫面結構（Tab Bar）

```
[首頁 / 追蹤]          [搜尋醫院]          [設定]
   🏥                     🔍                  ⚙️
   
目前追蹤             醫院地區列表          通知提醒閾值
追蹤卡片 x 1~3       搜尋列               背景刷新頻率
+ 新增追蹤           地區分類              關於 App
```

---

## 邊界情境

| 情境 | 處理方式 |
|------|----------|
| 醫師已下診（當日） | 通知「江建勰 04診 看診已結束」，自動停止追蹤 |
| 網路中斷 | 顯示最後更新時間，提示離線，停止輪詢 |
| 追蹤數達上限（3個） | 跳出提示「已達上限，請先停止一個追蹤」|
| 已在追蹤同一醫師 | 提示「江建勰 04診 已在追蹤中」，不重複建立 |
| 使用者拒絕通知權限 | 可正常追蹤，僅在 App 前台顯示進度，無背景通知 |
| 過號超過 3 分鐘 | 每分鐘提醒一次，最多提醒 3 次，之後停止追蹤 |
